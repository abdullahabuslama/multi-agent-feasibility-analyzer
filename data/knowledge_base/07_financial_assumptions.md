# NileCart — Financial Assumptions for Project Evaluation

> Synthetic document for training. NileCart is a fictional company.

Use these values in feasibility studies unless the project has better data.
All amounts are in Egyptian pounds (EGP) unless stated.

## General
| Item | Value |
|---|---|
| Planning exchange rate | 1 USD = 50 EGP |
| Hurdle rate (minimum annual return) | 25% |
| Maximum payback period for approval | 24 months |
| Contingency to add to cost estimates | 15% |
| Yearly budget for new initiatives (2026) | EGP 25 million |
| Inflation assumption for costs | 20% per year |

## People costs (fully loaded, per month)

## Business metrics

|---|---|

| Repeat purchase rate (12 months) | 41% |
| Support tickets per month | about 38,000 |
| Support cost per ticket | about EGP 21 (agent cost only) |
| Cost of a failed delivery | about EGP 65 |
| Monthly cloud spend | about EGP 3.1 million |

## Rules for the financial case
1. Show every assumption and its source.
2. Show a base case, a pessimistic case, and an optimistic case.
3. Include recurring costs (licenses, API usage, cloud, maintenance at
   15–20% of build cost per year, training).
4. Savings from fewer staff count only when the plan to reach them
   (hiring freeze, attrition, reassignment) is written down.
